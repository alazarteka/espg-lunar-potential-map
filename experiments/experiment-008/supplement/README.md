# Experiment 008 Supplement

`main.tex` is the self-contained scientific analysis and `main.pdf` is its
compiled record. Rebuild from the repository root with:

```bash
tectonic --outdir experiments/experiment-008/supplement \
  experiments/experiment-008/supplement/main.tex
```

Numerical tables are transcribed from the compact files under `../results/`.
Their exact hashes, together with the ignored replay caches, are recorded in
`../result-manifest.csv`.
