# Experiment 006 Supplement

`main.tex` is the tracked mini-paper for the restricted-domain beam-proxy
validation. At the design stage it records background, mathematical estimands,
expected failure modes, experimental design, and interpretation rules. Results
will be added only after the one-shot confirmation is complete.

Compile from this directory:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```
